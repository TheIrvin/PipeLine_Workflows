# Inicio rápido

1. Comprueba Docker y Compose desde Ubuntu.
2. Arranca `~/PipeLine_Workflows` con `docker compose up -d`.
3. Revisa `docker compose ps` y `./scripts/health-check.sh`.
4. Abre `http://localhost:5678` y crea manualmente el usuario propietario.

No se almacenan aquí contraseñas, tokens ni claves API.
